# Career Intelligence Platform

Автоматизированный сбор и анализ вакансий на n8n. Система сама собирает вакансии из открытых источников, размечает их по навыкам и грейдам, чистит от дублей, считает аналитику рынка труда и присылает еженедельный отчёт в Telegram.

Работает без участия человека — шесть воркфлоу по расписанию.

## Как это устроено

```
RemoteOK API ─┐
              ├─→ [Jobs] ─→ разметка ─→ [Analyzed Jobs] ─→ агрегация ─→ [Analytics] ─→ Telegram
Hacker News ──┘                              ↑
                                        дедупликация
```

![Воркфлоу сбора вакансий в n8n](IMG/1-1.jpg)

| Время | Что происходит |
|---|---|
| 09:30 | Сбор вакансий из RemoteOK |
| 09:31 | Сбор из Hacker News: лента YC и ежемесячный тред «Who is hiring?» |
| 09:40 | Разметка: навыки, грейд, категория, удалёнка |
| 09:44 | Чистка дублей и битых строк |
| 09:47 | Пересчёт метрик рынка |
| Ср 09:50 | Отчёт в Telegram |

Данные проходят четыре стадии, каждая на своём листе Google-таблицы. Любой этап можно перезапустить независимо от остальных.

Вся цепочка укладывается в двадцать минут одного утра. Причина не в спешке: система работает на домашнем компьютере, а n8n не выполняет пропущенное — этап, назначенный на время, когда машина выключена, просто выпадает, и следующий считает по вчерашним данным.

## Кому это полезно

**Соискателю** — какие навыки спрашивают на этой неделе, как распределены грейды, какая доля вакансий с удалённой работой. **Карьерному консультанту** — доказательная база вместо общих слов. **Рекрутеру** — понимание конкуренции за тех же кандидатов. **Автору курса** — обоснование программы по динамике за месяцы.

Схема переносится на любой поток однотипных записей: тендеры, объявления, товары конкурентов. Меняются два коллектора и правила разметки — остальные четыре воркфлоу остаются как есть. Подробнее — в [ОПИСАНИЕ.md](ОПИСАНИЕ.md).

## Решения, на которые стоит обратить внимание

**Дедупликация через `Set`.** Проверка вхождения не зависит от размера таблицы — при росте базы скорость не падает, в отличие от перебора массива для каждой вакансии.

**Приведение источников к общему формату.** RemoteOK и Hacker News отдают данные по-разному: у одного теги массивом и HTML в описании, у другого время в Unix-секундах и только ID вместо готовых записей. Оба приводятся к единой структуре, поэтому дальше системе всё равно, откуда пришла вакансия.

**Разбор объявлений по содержимому, а не по позиции.** Вакансии в треде Hacker News пишут строкой `Компания | Локация | Занятость | Должность`, но порядок полей соблюдают не все. Поэтому каждое поле опознаётся по признакам: локацию выдают города и слова `remote`/`onsite`, должность — ролевые слова. Если название должности в объявлении не выделено, ячейка остаётся пустой — это честнее обрывка описания, вписанного ради заполненности.

**Разделение сырых и обработанных данных.** Разметка пишется на отдельный лист, исходные данные не меняются — правила разметки можно переписать и прогнать заново по историческим данным.

**Пакетная обработка.** Разметка идёт через `Loop Over Items` порциями, что защищает от таймаутов при росте базы до тысяч строк.

**Накопительная аналитика.** Метрики не перезаписываются, а дописываются строкой в день — со временем получается история рынка, по которой видна динамика спроса на навыки.

## Запуск

Нужен Docker.

```bash
docker compose up -d
```

Дальше:

1. Открыть n8n на `http://localhost:5678`
2. Импортировать воркфлоу из `workflows/` (*Import from File*)
3. Создать credentials: Google Sheets OAuth2, Telegram Bot API
4. Заменить `YOUR_GOOGLE_SHEET_ID` на ID своей таблицы, `YOUR_TELEGRAM_CHAT_ID` — на свой чат
5. Создать в таблице листы `Jobs`, `Analyzed Jobs`, `Analytics`
6. Включить тумблер *Active* у всех шести воркфлоу

В `docker-compose.yml` указан часовой пояс `Europe/Bucharest` — от него зависит, в какое время сработают расписания. Поменяйте на свой.
